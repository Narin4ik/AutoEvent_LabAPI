# Музыка — AutoEvent_LabAPI 10.3.2

Фоновая музыка всех встроенных мини-игр повторяется с исходной скоростью и тональностью.
После окончания трек начинается заново. Его длина не подгоняется под длительность ивента.
Это относится к ручным запускам, периодической автоцепочке и непрерывному AutoRun.

Повтор включён также для Battle, Lava, Counter-Strike, Musical Chairs, Race,
Zombie Survival и финального Nuke Run. Паузы/возобновления в Musical Chairs продолжают
управляться правилами игры. В Zombie Survival вступительная музыка останавливается
перед основной темой; основная тема очищается и при ручной остановке игры.

Бомба, сигналы красного/зелёного света, победа, смерть и другие разовые эффекты
воспроизводятся однократно. Публичные методы `PlayAudio` и `PlayPlayerAudio` сохраняют
параметр `isLoop` с прежним значением по умолчанию `false`. Пользовательские ивенты
по-прежнему могут явно задать `SoundInfo.Loop`.

## Пользовательские треки

Файлы в папке `LabAPI/configs/AutoEvent/Music/` имеют приоритет над встроенными.
Сохраняйте имя и расширение заменяемого файла. Для OGG необходим декодер NVorbis
из установленного SecretLabNAudio. Путь к папке определяется конфигом AutoEvent.

Файл на диске и встроенный ресурс используют общий декодер и штатный повтор
`StreamAudioProcessor`. Звук приводится к игровому формату 48 кГц, моно через
`ToPlayerCompatible`, с сохранением времени и высоты тона; изменение скорости не применяется.
Не нужно удлинять файлы под игровой таймер.

При замене фонового трека старый проигрыватель останавливается. Очистка игры
освобождает её фоновую музыку, а выгрузка AutoEvent — все созданные им проигрыватели.
Повторная остановка одного дескриптора безопасна и не затрагивает следующую игру.

## Проверка

```powershell
dotnet run --project Tests/AutoEvent.Automatic.Tests.csproj -c Release
dotnet run --project Tests.Audio/AutoEvent.Audio.Tests.csproj -c Release
dotnet build AutoEvent.sln -c Release -p:CI=true
```

Тесты аудио используют настоящий SecretLabNAudio.Core 2.1.2, NAudio и декодер Vorbis.
Проверяются WAV 44,1/48 кГц, моно/стерео, исходные длительность и тональность,
три последовательных повтора, встроенный OGG и его файловая копия, освобождение файлов.
Отдельная симуляция проверяет паузу, возобновление, однократные эффекты,
остановку/выгрузку и неудачную инициализацию проигрывателя.

Аудиотесты работают на .NET 10 без Unity и сетевой передачи. Основная DLL остаётся
на .NET Framework 4.8 для LabAPI 1.1.7. Проверка звука у игроков на живом SCP:SL-сервере
этими тестами не заменяется.
